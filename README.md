# Prompt Templates

A curated collection of prompts, skills, and best practices for working effectively with AI coding agents.

## Structure

```
prompt-templates/
├── prompts/           # Reusable prompts for common tasks
├── skills/            # Agent skills/instructions for specialized domains
├── best-practices/    # Guidelines for working with AI agents
└── README.md
```

## Usage

Browse the directories above for ready-to-use prompts and patterns. Adapt them to your specific project context and AI agent.
